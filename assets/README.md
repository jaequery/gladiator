# assets/

Authored sources. What ships is compressed out of here by `pnpm assets:build`
into `packages/client/public/`.

```
assets/
  models/     .gltf + .bin — a Blender "glTF Separate" export
  textures/   .png — power-of-two, at least 4x4
```

Both these files and the artifacts they produce are committed. The full
reasoning, the Blender exporter settings, the texture classes, the lightmap
convention, the licence rules and the size budget are in
[`docs/assets.md`](../docs/assets.md). Three things worth knowing before you put
anything here:

1. **Add an entry to [`credits.json`](../credits.json) for every file.** A
   committed file in this directory with no entry fails the build, by name.
2. **Content is CC0 or it does not ship.** Not CC-BY. OpenGameArt and Freesound
   are mixed-licence and have to be filtered to CC0 per item, and Mixamo is
   rejected outright — its licence forbids redistributing the raw asset files,
   which is what committing one here would do.
3. **Authoring files are gitignored** — `.blend`, `.psd`, `.wav` and friends.
   Keep them somewhere backed up; the export is what belongs in the repository.

Then run `pnpm assets:build` and commit what it writes.

Everything currently in here is a placeholder generated by
`pnpm assets:placeholders`, which is also why it is unambiguously CC0: a program
in this repository wrote it, and the program is
[`tools/assets-placeholders.ts`](../tools/assets-placeholders.ts).
